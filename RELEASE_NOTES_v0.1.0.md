## ReckonFlow v0.1.0

Headless FastAPI backend for corporate travel: approvals, immutable double-entry ledger, receipt extraction, hybrid bank reconciliation.

- Idempotent mutating writes (Redis)
- Redis rate limiting with in-memory fallback
- Alembic migrations, mypy, pytest in CI
- Docs: https://ikrame-ih.github.io/reckon-flow/
- Live API: https://reckon-flow.onrender.com/docs
